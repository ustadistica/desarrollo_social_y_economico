================================================================================
                              SOLUCIÓN RÁPIDA
================================================================================

1. CLONAR REPOSITORIO:
   cd /ruta/a/CONSULTORIA
   git clone <URL_DEL_REPO>
   cd desarrollo_social_y_economico

2. DESCARGAR CARPETA "Datos" (les daré el link):
   - Descomprimirla en: CONSULTORIA/Datos/
   - Debe contener:
     * CENSO 2018 dep/
     * EMICRON 2019/, EMICRON 2020/, ..., EMICRON 2024/
     * SECOP_I_-_Procesos_de_Compra_Pública_*.csv
     * SECOP_II_-_Contratos_Electrónicos_*.csv
     * PPED-AreaDep-2018-2050_VP.csv

3. INSTALAR PYTHON:
   python -m venv .venv
   .venv\Scripts\activate      # Windows
   source .venv/bin/activate   # Mac/Linux
   pip install -e .

4. VERIFICAR CONFIGURACIÓN:
   python -m src.validadores.verificar_datos

   Si ves ✅ en todo, continúa. Si ves ❌, la carpeta "Datos" no está bien.

5. EJECUTAR PIPELINE (puede tardar 15-25 minutos):
   python src/ingesta/run_bronze.py
   python src/transformacion/run_silver.py
   python src/transformacion/run_gold.py

6. USAR RESULTADO FINAL:
   datos/oro/marts/latest/mart_desarrollo_social_economico_municipio_anio.parquet

   En Python:
   import pandas as pd
   obt = pd.read_parquet("datos/oro/marts/latest/mart_*.parquet")
