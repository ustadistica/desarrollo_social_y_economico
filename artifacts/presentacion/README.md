# Presentación preliminar

Boceto en Markdown compatible con [Marp](https://marp.app/) para exportar a PDF o HTML.

## Exportar

Con Marp CLI:

```bash
npx @marp-team/marp-cli@latest presentacion.md --pdf
npx @marp-team/marp-cli@latest presentacion.md --html
```

Con VS Code: instalar la extensión *Marp for VS Code* y usar "Export slide deck".
